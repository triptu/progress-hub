How the progress hub works

Agents write plain Markdown pages. One small program on this machine reads those pages and, when you use T3 Code, its database, and serves the app you open. It all runs on this machine.

Walk through it

Pick one to see its path light up, step by step.

    The hub reads
    The pages, every 2 seconds. T3 Code's database, when there is one, read-only. GitHub, through gh.
    The hub writes
    Files of its own: .history.jsonl in each work, and your marks and todos in .marks.json and .todos.json. It never edits a page.
    It runs as
    A login service, progress.hub, running ~/.local/bin/progress serve. setup.sh installs it.
    It answers
    Only this machine and its tailnet name, on port 4747.
